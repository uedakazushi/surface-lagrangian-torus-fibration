\section{五次・六次全平面模型の大域作用適合 atlas}
\label{ga8:section}

局所 cone charts，実際の二重曲線上の面積，normal framing，および
有限の平滑化 parameter における作用の加法定数を，ここで一つの構成にまとめる．
必要なのは，既製の二つの foliations を単に isotopy で結ぶことではない．
同じ actual Hamiltonian neck 上で critical actions を指定された直線に保ち，
その共通 Hamiltonian が各 branch star で ambient-affine になることを用いる．

\begin{theorem}[五次・六次の作用適合 matroidal atlas]
\label{ga8:global}
$d\in\{5,6\}$ とし，$X_d\subset\PP^3$ を任意の滑らかな次数 $d$ の曲面，
$\omega$ を $[\omega]=aH$，$a>0$ を満たす任意の K\"ahler form とする．
定理~\ref{main:global} の全平面構成を選び，その fibration
\[
 \pi:(X_d,\omega)\longrightarrow B_d
\]
について，定義~\ref{atl:definition} の，focus--focus 特異点を許す
作用適合 matroidal atlas を構成できる．
全ての branch denominator は $q=1$ である．

$d=5$ では五つの core charts を標準 $K_4$ fan とし，
系~\ref{qg8:six-systems} の六つの標識付き対称有向四角形系のいずれも選べる．
$d=6$ では六つの core charts を標準 Petersen fan とし，
定理~\ref{topo:petersen} の六つの標識付き同時 Petersen systems のいずれも選べる．
それぞれの実際の二重曲線上で，対応する embedded marked pants class を先に固定できる．
foliation の代表は，以下の面積条件を満たすようにその class 内で選ぶ．

構成の個数と面内の node 配分は次の通りである．
\begin{center}
\begin{tabular}{c|ccccc}
 $d$ & cores & branch edges & triangles & bigons & focus points\\ \hline
 $5$ & $5$ & $10$ & $10$ & $0$ & $50$\\
 $6$ & $6$ & $30$ & $20$ & $15$ & $90$
\end{tabular}
\end{center}
五次では各 triangle に五つの focus points があり，
六次では各 triangle に三つ，各 bigon に二つある．
全ての branch edges の primitive affine length は
\begin{equation}\label{ga8:branch-length}
 \frac{a}{\pi(d-1)}
 =\begin{cases}a/(4\pi),&d=5,\\a/(5\pi),&d=6\end{cases}
\end{equation}
である．底空間の homotopy 型はそれぞれ
$\bigvee^4S^2$ と $\bigvee^{10}S^2$ である．

focus values 自体は通常の matroidal charts の定義域から除き，
その穿孔近傍には実際の nodal fibration の作用アフィン構造を用いる．
core fibers は元の直線補集合の logarithmic skeleton の symplectic images である．
特に Petersen fan という結論は，core の symplectic filling を
標準 $M_{0,5}$ の filling と同定する主張ではない．
\end{theorem}

証明の前に，実際の成分へ移す際に使う二点を明示する．

\begin{lemma}[有限標識点も固定する divisor-relative Moser]
\label{ga8:fixed-q}
補題~\ref{glue:pair-moser} の仮定の下で，crossings を避けた divisor 上の
有限個の相異なる点を指定する．その結論の isotopy は，これらの点も
全 parameter で固定するように選べる．
\end{lemma}

\begin{proof}
$\dd\alpha_s=\partial_s\omega_s$ を取り，crossing balls の小近傍で
$\alpha_s=0$ とする，元の証明から始める．指定点 $q\in C$ ごとに
\[
 g_s(q)=0,\qquad
 (\dd g_s)|_{T_qC}=-\alpha_s|_{T_qC}
\]
という first jet を指定し，互いに素な小近傍に支持された滑らかな関数
$g_s$ として延長する．$\alpha_s$ を $\alpha_s+\dd g_s$ で置き換えると，
crossing balls の条件とその微分は変わらず，指定点での tangent restriction が零になる．

次に，$N_s=(TC)^{\omega_s}$ に沿う元の normal-jet correction
\[
 F_s|_C=0,\qquad (\dd F_s)|_{N_s}=-\alpha_s|_{N_s}
\]
を行う．$F_s|_C=0$ なので tangent restriction は変更されない．
従って $\eta_s=\alpha_s+\dd F_s$ は各指定点で covector として零である．
$\iota_{Y_s}\omega_s=-\eta_s$ を解けば，$Y_s$ は全 divisor に接し，
指定点およびより小さい crossing balls で零になる．
その Moser flow が主張を満たす．
\end{proof}

\begin{lemma}[実成分への移植と critical action germs]
\label{ga8:affine-persistence}
命題~\ref{per:k4-realization} または定理~\ref{per:local-realization} の
core model において，nodal blow-up patches を全 critical leaves から離して取る．
局所 nodal comparison，divisor-relative Moser，および
補題~\ref{glue:circle} の normal-circle conjugacy の後も，
実際の二重曲線に十分近い critical action germs は，normal moment の
整数勾配を持つ affine functions である．
共通 neck framing へ直すときの勾配の変化は，
補題~\ref{qg8:framing} または命題~\ref{sg8:framing} に記した整数 shear である．
\end{lemma}

\begin{proof}
core model の proportional-curvature collar では，これらの作用は
normal action $\rho-w$ の定数倍であり，指定した recipes ではその係数が整数である．
flat-ball の準備，局所 blow-up，および相対 almost-toric comparison は，
critical leaves の全 germ の外に支持を取れる．従ってこの段階では
critical germs とその作用関数は変更されない\cite[Theorem~1.1]{CGblowup}．

divisor-relative Moser は critical leaves を点ごとに固定する必要はない．
この symplectomorphism により，fibration の germ 全体，その周期 cycles，
primitive，および normal circle action を共に運ぶ．
作用関数の値と moment の関係は，この同時輸送で保たれる．
続く circle conjugacy は divisor を点ごとに固定し，
normal weight $+1$ の作用を actual neck の作用へ合わせる．
moments は divisor 上で零と正規化するので，両 moment の間に加法定数は残らない．
crossing germs を固定し，余分な $U(1)$ gauge winding を入れない同定を用いる．

運ばれた primitive と，節~\ref{ng8:section} の一つの neck primitive の差は，
共通 collar 上で closed である．連続に運ばれる同じ cycle に対するその積分は定数なので，
critical actions の変化は加法定数だけである．
cycle framing を $\beta\mapsto\beta+m\alpha$ と変えたときは，
さらに $m\mu$ が加わる．従って affine 性と整数勾配が保たれ，
残る勾配の比較は actual normal-bundle clutching の計算に正確に帰着する．
\end{proof}

\begin{proof}[定理~\ref{ga8:global} の証明]
\textit{偏極と有限個の marked データを準備する．}
成分を $i=0,\ldots,d-1$ と標識し，十分小さい $\eps>0$ に対して
\[
 \beta_i=(i-d+1)\eps,\qquad
 b_i=\frac{\beta_i}{2\pi},\qquad
 c_d=\frac{a}{2\pi(d-1)},\qquad
 w_{i,j}=c_d+b_j-b_i
\]
と置く．この ray は定理~\ref{pol:cone} の K\"ahler simplex の内部にあり，
例えば $\eps<a/d^2$ とすれば全 weights は正である．
実際の surgeries の capacity を確保するためには，後でさらに $\eps$ を小さくする．
各 blow-down component における直線の面積は
\[
 2\pi R_i,\qquad
 R_i=(d-1)c_d+\sum_jb_j-db_i
     =\sum_{j\ne i}w_{i,j}
\]
である．$i<j$ の二重曲線の $d$ 個の blow-up sizes は全て
$2\pi\delta_{ij}$，$\delta_{ij}=b_j-b_i$ である．

五次では六つの対称有向四角形系の一つを取り，その代表を
$f_i(j)=(i+j)/2$ on $\mathbb F_5$ としてよい．
各 $C_{ij}$ の三つの basins に，選択した一領域へ三点，残る二領域へ一点ずつ，
実際の $q_{ij,r}$ を割り当てる．
六次では選んだ同時 Petersen system に従って各 $C_{ij}$ の quartet を固定し，
四つの external basins に一点ずつ，内部 annulus に二点を割り当てる．
同じ $C_{ij}=C_{ji}$ 上で embedded marked class を先に選び，
各 $q_{ij,r}$ を相異なる regular leaves に置く．
補題~\ref{qg8:marked-allocation} と節~\ref{sg8:section} の density--Moser argument により，
crossing disks と有限個の標識点の近傍を固定してこの選択ができる．

blow-down で指定する basin areas は，五次では
$2\pi(w_{i,k}+\epsilon_{i;jk}w_{i,j})$，六次では $2\pi w_{i,k}$ である．
六次の内部 annulus の面積は $2\pi w_{i,j}$ とする．
指定点近傍の flat-ball 準備は critical leaves を避けた一領域内の exact modification なので，
その領域全体の積分を変えない．
normal-coupling の準備も divisor の制限形式を保つ．
その後の blow-up は，含まれる領域の面積から一個につき $2\pi\delta_{ij}$ を引く．
従って，実際の strict curve 上の対応する領域面積は，
定理~\ref{qg8:unique-weights} および命題~\ref{sg8:areas} によって両側で一致する．
全ての目標面積は正である．これが中央曲線における面積の条件である．

crossing germs，marked foliations，および regular patches は，
$\eps=0$ の blow-down データから小さい parameter 族として準備できる．
有限個の patch capacities は正の下限を持つので，この準備の後で $\eps$ を縮める．
実際の全空間の neck 平均化と三重点の product germs は，
節~\ref{sec:necks} の fixed-class 構成で先に準備する．

\textit{core charts と nodes を実際の成分上へ移す．}
各 blow-down component に定理~\ref{snc:main} の相対構成を施し，
上記の面積を持つ foliation を用いて，五次では命題~\ref{per:k4-realization}，
六次では定理~\ref{per:local-realization} の charts を取る．
全ての surgeries は core と critical collar germs の外の regular patches 内で行う．
局所比較定理は patch の外で恒等であるから，一個の blow-up ごとに
一個の compact focus--focus fiber が入り，core charts は保たれる．

モデルの blow-up 形式から actual $\Omega_i$ への同定には，
補題~\ref{ga8:fixed-q} を用いて各 strict curve 上の標識点も固定する．
これは crossing disks を固定する divisor-relative isotopy であるから，
両側の reduced foliations は先に選んだ同じ marked class に留まる．
全ての basin と annulus は形式と共に運ばれるので，既に確認した実面積の一致も保たれる．
両側の embedded critical leaves がこの段階で点ごとに一致する必要はない．
次の neck 補間に必要なのは，同じ marked class と対応する critical-region areas である．

次に補題~\ref{glue:circle} を適用する．
core と compact nodal fibers 全体を避けるほど細い collar で normal actions を合わせる．
補題~\ref{ga8:affine-persistence} により，実際の成分側の critical actions はなお affine である．
五次では補題~\ref{qg8:framing} と命題~\ref{qg8:slope}，
六次では命題~\ref{sg8:framing} が，両側を共通 neck framing に直した後の
整数勾配の一致を与える．この順序では，nodal monodromy と normal-bundle winding を
葉層の isotopy で消したことにはしていない．

\textit{有限の平滑化 parameter で critical actions を接続する．}
ここでの neck は，既に確保した compact nodal neighborhoods を避ける
source-free collar であり，固定 $t\ne0$ の全 moment band で circle action は自由である．
各二重曲線について，中央 strict curve 上の面積一致と整数勾配の一致が揃ったので，
系~\ref{ng8:central-criterion} を適用する．
puncture cuts と保存する collars を先に十分小さく選び，その後で正の切断値
$\delta$ を選ぶ．一つの全空間 primitive と toric reference actions を用いるため，
中央曲線上で一致した critical action intercepts は，共通の意味を持つ．
固定した $\mu=\delta$ と $\mu=-\delta$ の open buffers を nearby fiber に運ぶと，
補題~\ref{ng8:transport-intercept} はこれらの作用関数そのものを保存する．
ここでは $\mu=0,t=0$ を通る輸送も，$\delta\to0$ に一様な輸送も使わない．

残る interval では命題~\ref{ng8:straight-neck} により，
end germs と toric collars を保って measured critical regions を補間する．
total reduced area との整合は補題~\ref{ng8:relative-dh} の affine Stokes formula による．
中央曲線で正の basin および annulus areas は，$\delta$ を縮めれば全 interval で正となり，
保存する領域に対する面積の余裕も確保できる．
従って，actual neck 全体の critical actions は同じ整数勾配の affine functions となる．
三重点では固定した toric leaves を使い，節~\ref{glue:hexagon} の
飽和した affine moment cuts によって components と necks を接続する．

core と nodal fiber 全体およびその飽和近傍は，
補題~\ref{glue:transport} による固定 compact subset の輸送で保存する．
全 interface は whole fibers の和であり，open overlap 上で実際の葉層が一致する．
節~\ref{sec:gluing} の properness と飽和 quotient の議論が適用され，
追加の特異 fibers を生じずに，compact $X_t$ 上の fibration を得る．

\textit{facewise actions を一つの atlas にする．}
core の近傍には既に $K_4$ または Petersen charts がある．
各 branch の内部では，critical actions の整数勾配と
simple-saddle の transverse action の strict monotonicity により，
補題~\ref{atl:qone-chart} の chart が得られる．
その共通 Hamiltonian は，neck の normal moment $\mu$ である．
core chart 側でも，同じ作用は ambient-affine である．
$K_4$ の場合は \eqref{per:k4-lattice-map} の $\Phi$ を用い，
Petersen の場合は補題~\ref{per:branch-duality} の saturated branch-star lattice を用いる．
加法定数は core primitive と neck primitive の正規化の差として許される．
この Hamiltonian は branch tangent に沿って primitive な非零勾配を持つ．

正則 faces では実際の fibration の通常の action charts を使う．
これらと core および branch charts は同じ作用格子に適合し，
branch を横切る overlap では共通 Hamiltonian が両方で ambient-affine である．
従って命題~\ref{atl:gluing-criterion} により，transition とその逆は
ambient integer affine maps の制限となる．
五次の明示的な変換は命題~\ref{qg8:star-transition}，
六次の変換は補題~\ref{sg8:star} にも記した通りである．
cocycle identity は実際の chart transitions の合成として成り立つ．
focus--focus values の穿孔近傍には，既存の compact nodal model の作用格子を用いる．
その非自明 monodromy を通常の smooth matroidal chart で埋めることは要求していない．

\textit{個数，長さ，および指定された K\"ahler form を確認する．}
五次の一つの triangle では，三つの pair のうち選択 basin となる pair が一つなので，
node 数は $3+1+1=5$ である．
六次では各 triangle が三つの external basin nodes を持ち，
各 bigon が一つの内部 annulus の二つの nodes を持つ．
他の cell counts と homotopy 型は定理~\ref{main:global} による．
branch 上の normal action の原点は，$i$ core では $\mu=w_{i,j}$，
$j$ core では $\mu=-w_{j,i}$ にある．
全区間で primitive な勾配は一なので，その affine length は
$w_{i,j}+w_{j,i}=2c_d$ となり，\eqref{ga8:branch-length} を得る．

最後に，全空間の exact modifications を compact $X_t$ 上で Moser により戻す．
さらに，滑らかな次数 $d$ の射影超曲面の connected family に沿う symplectic transport と，
同一 class の K\"ahler forms の凸結合に対する Moser を用いて，
任意の指定された $(X_d,\omega)$ へ移す．
これらは fibration と作用格子を共に運ぶ symplectomorphisms であり，
atlas の存在，整数勾配，focus monodromy，および affine lengths を保つ．
\end{proof}

\begin{remark}[構成の量化]
本定理は，各次数について作用適合 atlas を持つ fibration の存在を述べる．
既に任意に固定された basin areas，normal holonomies，または end germs 全てが
この方法で接着できるという主張ではない．
また，K\"ahler simplex の全点で所定の容量の surgeries を実行する必要はなく，
十分小さい vertical ray を用いている．
六つの標識付き recipes または graph systems の実現は，
六つの相異なる大域 affine-isomorphism classes の分類を意味しない．
\end{remark}


\subsection{Actual link の有限 period 条件と Liouville core}

ここでは component の Liouville domain，primitive，canonical normal moments，
保持 corner と anchor cuts を固定する．比例曲率の模型への移植を入力とせず，
actual link の葉を選び直すための有限条件を記す．ただし source を含む保持領域を
避けた面積調整の存在は別問題であり，以下の period 条件だけからは結論しない．

\begin{lemma}[Anchor の period と core へ向かう critical action]
\label{ke:anchor-liouville-actions}
補題\ref{ke:actual-link-cone-filling}の $(K,d\lambda)$ と link $S$ を取り，
normal face では周期 $1$ の actual generator $V_a$ に対して
\[
 \mathcal L_{V_a}\lambda=0,\qquad
 \lambda(V_a)=M_a=q_a-\rho_a,\qquad q_a|_S=\delta_a<\rho_a
\]
とする．$q_a=\epsilon_a\widehat\mu_N$ は加法定数まででなく，
既存の canonical moment と厳密に同じものとする．
この face の一つの critical fiber 上の標識 cycle $\beta$ の period を
$A=\int_\beta\lambda$ と書く．Critical cycle の積分は，必要なら隣接する
regular annuli の極限で解釈する．

同じ link の葉を Liouville flow によって充填すると，
その critical ray 上の period は
\begin{equation}\label{ke:eq:anchor-action-ray}
 I_\alpha(r)=r(\delta_a-\rho_a),\qquad I_\beta(r)=rA,
 \qquad 0<r\le1.
\end{equation}
従って，元の actual normal circle が定義される共通 collar では
\begin{equation}\label{ke:eq:anchor-action-line}
 q_a(r)=\rho_a+r(\delta_a-\rho_a),\qquad
 I_\beta(q_a)=\frac{A}{\delta_a-\rho_a}(q_a-\rho_a).
\end{equation}
右辺の $q_a(r)$ は，collar の外では transport した local normal action の
連続延長を表す．元の canonical circle action が全 core に存在する，という
主張ではない．

同じ primitive と cycle framing で指定された neck の直線 $c+pq_a$ が
この Liouville germ と一致するための必要十分条件は
\begin{equation}\label{ke:eq:anchor-intercept}
 A=p(\delta_a-\rho_a),\qquad c=-p\rho_a
\end{equation}
である．整数勾配を要する場合は $p\in\mathbb Z$ を要求する．
\end{lemma}

\begin{proof}
$\iota_Zd\lambda=\lambda$ より $\lambda(Z)=0$，
$\mathcal L_Z\lambda=\lambda$ である．従って
$\varphi_s^*\lambda=e^s\lambda$．$r=e^s$ と置けば，全ての標識 cycles の
period が同じ倍率 $r$ を受け，\eqref{ke:eq:anchor-action-ray}を得る．
Collar では $[Z,V_a]=0$ なので，transport した normal cycle は元の actual
circle cycle と同じであり，厳密な moment 規格化から
\eqref{ke:eq:anchor-action-line}が従う．二つの affine functions の
係数を比較すると\eqref{ke:eq:anchor-intercept}を得る．
この計算は critical cycles を regular cycles で近似した場合にも連続性で成立する．
\end{proof}

\begin{remark}[Primitive と framing を変えて比較するとき]
Neck primitive $\lambda_N$ と core primitive $\lambda$ の差は共通 collar で
closed である．同じ標識 cycle $\beta$ に対し
$\kappa=\int_\beta(\lambda_N-\lambda)$ は collar 内で定数であり，
normal cycle 上の差は $\rho_a$ である．比較 cycle を
$\beta_N=\varepsilon\beta+k\alpha$，$\varepsilon\in\{1,-1\}$，
$k\in\mathbb Z$ とする場合には，neck action は
\[
 I^N_{\beta_N}(q_a)
 =\varepsilon\frac{A}{\delta_a-\rho_a}(q_a-\rho_a)
   +\varepsilon\kappa+kq_a.
\]
従って直線 $c+pq_a$ との一致条件は
\[
 p=k+\varepsilon\frac{A}{\delta_a-\rho_a},\qquad
 c+\rho_a(p-k)=\varepsilon\kappa.
\]
最後に $q_a=\epsilon_a\widehat\mu_N$ へ戻す．閉形式の残余 period を
零と仮定したり，component ごとに neck primitive の切片を独立に消してはならない．
Exact な primitive 補正 $\lambda\mapsto\lambda+dF$ は，固定した cycle の
period を変えないため，この条件の不足を自動的に修復しない．
\end{remark}

\begin{proposition}[Actual anchor periods による $K_4$／Petersen core chart]
\label{ke:actual-anchor-fan-criterion}
補題\ref{ke:actual-link-cone-filling}の actual domain と invariant primitive を
固定し，link は normal faces と保持 corner の torus-orbit caps からなるとする．
Normal face $a$ の quotient は $d-2$ 個の境界を持つ球面で，
$M_a=\delta_a-\rho_a<0$ はその face 全体で一定である．
各 normal--corner overlap では標識 cycles が既存の同じ actual torus を通じて
一致するものとする．特に二つの正の meridians は整数 torus basis であり，
保持 corner と end collars の各 meridian period は負である．

各 normal face に，次の period を持つ actual reduced Morse foliation を
与え，end collars では保持 torus partition と一致すると仮定する．
\begin{enumerate}
\item $d=5$ では四つの boundary lines の有向四角形 $f$ を選ぶ．
Face $a$ の一つの critical fiber 上で，puncture $b$ から運んだ meridian
$\beta_b$ の period は
\[
 \int_{\beta_b}\lambda=-M_a\mathbf1_{\{b=f(a)\}}.
\]
\item $d=6$ では Petersen 型の labelled quartet system を選ぶ．
Face $a$ の四つの external critical basins の，puncture から運んだ cycles の
period は全て零とする．内部 annulus の cycle は，二つの端でそれぞれ
$0$ と $-M_a$ の period を持つものとする．この後者の条件は，
実際の torus cycle の Euler framing relation と外側の零 period から従う場合には
独立な条件でない．
\end{enumerate}
Normal face の regular annuli では，これらの標識 cycles の period 差が
向き付けた reduced annulus の面積に等しいとする．これは一つの primitive と
固定 framing を用いた Stokes の同定であり，独立な second-action gauge の
一致を仮定することではない．

このとき，同じ link 葉を用いた Liouville filling は，core の近傍に
作用座標に適合する標準 $K_4$，それぞれ Petersen cone chart を持つ．
各 face と branch の格子は飽和し，全 branch denominator は $1$ である．
元の Liouville domain，その skeleton と等方的 filtration は変えない．
保持 corner の全 torus 葉と cap arcs も保存される．
さらに各 branch star で，その normal action の延長 $q_a$ はこの chart の
ambient integer affine function であり，branch tangent 上の勾配は primitive
で非零である．
\end{proposition}

\begin{proof}
$K_4$ の crossing face $ab$ では，既存の整数行列
\[
 A_{ab}=\begin{pmatrix}-1&\epsilon_{ba}\\
                         \epsilon_{ab}&-1\end{pmatrix},\qquad
 \epsilon_{ab}=\mathbf1_{\{b=f(a)\}}
\]
を使って $(I_a,I_b)^T=A_{ab}(t_a,t_b)^T$，
$F=t_ar_a+t_br_b$ と定める．有向四角形には二辺 cycle がなく，
$\det A_{ab}=1$．仮定の critical periods により各 branch 上では
$F=(-M_a)r_a$ となり，隣接 face maps が一致する．

正値性には比例曲率を使わない．例えば $a\to b$ なら
$t_a=-I_a$，$t_b=-I_a-I_b$ である．$a$ 側の normal face では
$I_a=M_a<0$ が一定で，$I_b$ は負の reference value から
$-M_a$ へ面積に従って厳密単調に増える．従って critical endpoint を除き
$t_a,t_b>0$．$b$ 側では $I_a<0$，$I_b=M_b<0$ から同じ結論を得る．
非選択辺では $t_a=-I_a$，$t_b=-I_b$．保持 corner と丸めでは
両 meridian periods が負なので，どの場合も係数は正である．

Petersen の crossing faces では
$F=-I_ar_v-I_br_w$，内部 faces では
\[
 F=(-I_a-I_\beta)r_A+I_\beta r_B
\]
とする．前者では external periods が負から零へ増え，
後者では $I_\beta$ が $0$ から $-M_a>0$ へ増える．従って両係数は
regular interior で正であり，端点では所定の共通 ray に一致する．
二つの係数への行列の determinant はそれぞれ $1$，$-1$ である．
Cycle framing は実際の overlap で一致するので，これらは単なる抽象 graph の
同定から作った period maps ではない．

各 link edge の parameter を $u$ とし，その action vector を $a(u)$ とする．
Liouville cone 上の作用写像は $(r,u)\mapsto ra(u)$ である．
正則 Lagrangian fibration の作用座標は局所座標だから
$\det(a(u),a'(u))\ne0$．上の整数行列で正の sector coefficients
$\tau(u)=(\tau_1(u),\tau_2(u))$ へ移すと，同じく
$\det(\tau,\tau')\ne0$ であり，
\[
 \theta(u)=\frac{\tau_2(u)}{\tau_1(u)+\tau_2(u)},\qquad
 \theta'(u)=\frac{\det(\tau(u),\tau'(u))}
                    {(\tau_1(u)+\tau_2(u))^2}\ne0.
\]
開辺は連結なので微分の符号は一定で，両端では $\theta$ は $0$ と $1$ になる．
従って projective action ratio は二つの boundary rays の間を一度だけ走る．
Radial scaling と合わせ，各 face map は所定の cone sector の原点近傍へ同相を与える．
有限個の edges と compact な link を用い，原点近傍を共通に縮めればよい．
Ray 上の係数は全 incident faces で同じであり，標準 fan の face lattices と
上の行列は unimodular なので，branch lattices も飽和する．

Normal period の ambient integer linear extension を直接記す．$K_4$ では
\eqref{per:k4-lattice-map}の
$\ell_a=e^*_{f^{-1}(a)}-e^*_a$ が全 incident faces で
$\ell_a(F)=I_\alpha$ を満たす．Petersen では branch $v$ の二つの crossing
neighbors を $x,y$，matching neighbor を $z$ とすると，
補題\ref{per:branch-duality}の saturated star lattice の基底
$(r_v,r_x,r_y)$ に対して $r_z=r_v-r_x-r_y$ である．
この基底上で $\ell_a=(-1,0,0)$ と取れば $\ell_a(r_z)=-1$ であり，
crossing face と matching face の表示から，いずれでも
$\ell_a(F)=I_\alpha$ となる．Star lattice の飽和性により，この covector は
ambient integer covector に延長できる．従って両場合とも
$q_a=\ell_a(F)+\rho_a$ は ambient integer affine であり，
branch ray の primitive generator での値が $-1$ なので，その勾配は primitive
で非零である．

補題\ref{ke:anchor-liouville-actions}が，全 radial levels へ同じ関係を
運ぶ．Core point への一様収束と全 singular strata の等方性，skeleton の
連結性は補題\ref{ke:actual-link-cone-filling}の同じ filling から従う．
Corner では invariant primitive の Liouville flow が actual torus action と
可換であり，torus orbits の全 partition を保つ．従って保持 cap arcs を含む
全 corner overlap に余分な葉の接着条件を生じない．
\end{proof}

\begin{lemma}[Normal face の Stokes 総量と必要な target areas]
\label{ke:anchor-stokes-budget}
固定 normal face の circle bundle $E\to P$ を取り，$P$ は $k$ 個の境界を
持つ球面とする．Normal cycle を $\alpha$，各 puncture を正に回る，
指定された実際の lift cycles を $\beta_b$ とする．
Clutching relation と primitive の period を
\[
 \sum_{b=1}^k[\beta_b]=-[\alpha]\quad\hbox{in }H_1(E;\mathbb Z),
 \qquad \int_\alpha\lambda=M<0,\qquad
 c_b=\int_{\beta_b}\lambda
\]
と仮定する．ここで homology relation に非閉形式 $\lambda$ を直接積分しない．
Reduced form を $\omega_P$ とすると
\begin{equation}\label{ke:eq:anchor-area-total}
 \operatorname{Area}(P)=-\sum_bc_b-M.
\end{equation}
従って $K_4$ の target critical periods
$A_b=-M\mathbf1_{\{b=f(a)\}}$ に必要な basin areas は
$a_b=A_b-c_b$ で，その和は厳密に全体面積に等しい．
Petersen の external target $A_b=0$ に必要な外側 basin areas は $a_b=-c_b$，
内部 annulus の target area は $-M$ であり，これらの和も厳密に全体面積に等しい．
\end{lemma}

\begin{proof}
$H^2(P;\mathbb Z)=0$ なので bundle を自明化し，周期 $1$ の座標 $\theta$ と
global section を選ぶ．Circle invariance と $M$ の一定性から
$\lambda=M\,d\theta+\pi^*\beta$ と書け，$d\beta=\omega_P$．
$\beta_b$ の section に対する整数 winding を $n_b$ とすれば，
clutching relation より $\sum_bn_b=-1$ である．
正の puncture circle $\gamma_b$ の向きは $P$ の境界向きと反対なので
\[
 \int_P\omega_P=-\sum_b\int_{\gamma_b}\beta
 =-\sum_b(c_b-Mn_b)=-\sum_bc_b-M.
\]
同じ固定 framing を critical cycle まで運ぶと，annulus の Stokes は
$a_b=A_b-c_b$ を与える．各指定値を代入すると残りの結論を得る．
\end{proof}

\begin{corollary}[保護 tail periods による五次 anchor の有限判定]
\label{ke:k4-protected-anchor-selection}
五次の一つの actual core において，四つの normal faces を
$a\in\{1,2,3,4\}$ で標識する．各 face は三つの punctures
$b\ne a$ を持つ pair of pants であり，前補題の clutching と
同じ transported meridian framings を仮定する．
各 face の初期 reduced foliation は一つの simple saddle を持ち，
保持集合は end collars と external basins の内部の互いに素な飽和
regular annuli からなるものとする．
Critical leaf の近傍には自由部分を残し，marked relative isotopy class を固定する．
Normal period は $M_a<0$，puncture period は $c_{ab}$ とする．

Basin $ab$ の critical leaf に最も近い保持 annulus の critical leaf 側の境界から
puncture までの全 tail の面積を $L_{ab}$ とする．内部に保持 annulus がなければ，
end collar の面積を $L_{ab}$ とする．Tail には隔離された自由部分も含める．
その critical leaf 側の境界へ同じ meridian framing を運んだ period は
\begin{equation}\label{ke:eq:k4-protected-period}
 Q_{ab}=c_{ab}+L_{ab}.
\end{equation}
Face $a$ で指定した successor $b_*$ に対する $K_4$ target
\[
 A_{ab}=-M_a\mathbf1_{\{b=b_*\}}
\]
を保持集合上の全葉を変えずに実現できるための必要十分条件は
\begin{equation}\label{ke:eq:k4-protected-inequalities}
 Q_{ab_*}<-M_a,\qquad Q_{ab}<0\quad(b\ne a,b_*).
\end{equation}
これはこの相対面積問題の判定であり，任意の葉層変更についての必要条件ではない．

従って，各 face の許容 successor 集合 $S_a$ は次の三通りである．
\begin{enumerate}
\item 全ての $Q_{ab}$ が負なら，$S_a=\{b:b\ne a\}$．
\item 非負の $Q_{ab}$ がただ一つ $Q_{ab_*}$ で，
      $Q_{ab_*}<-M_a$ なら，$S_a=\{b_*\}$．
\item それ以外では $S_a=\varnothing$．
\end{enumerate}
全 $S_a$ が非空とする．Singleton の $S_a$ が指定する arrows を forced arrows と呼ぶ．
四つの faces の targets を一つの有向四角形 $f$ として選べるための必要十分条件は，
forced arrows の終点が互いに異なり，その中に長さ $2$ 又は $3$ の
有向 cycle がないことである．既に一つの長さ $4$ の cycle をなす場合は許される．

これらの条件が成り立ち，保持 corner の実際の torus markings が
命題\ref{ke:actual-anchor-fan-criterion}の条件を満たすなら，
同命題に必要な四つの anchor foliations と $K_4$ core chart を構成できる．
この結論は固定した core・normal faces のものであり，
反対側の neck との全 moment interval 上の整合は含まない．
\end{corollary}

\begin{proof}
固定 face の作用は自由であり，同じ section framing で
tail annulus に Stokes を適用すると，その面積は内側と puncture の
period の差である．これが\eqref{ke:eq:k4-protected-period}を与える．
保持 annuli によって tail が細分されていても，途中の period は相殺する．

必要な全 basin areas は前補題により
$a_{ab}=A_{ab}-c_{ab}$ であり，その和は全体面積と一致する．
Pair of pants の Reeb tree には internal region がない．
従って系\ref{ng8:ordered-source-area-cuts}の全条件は
$a_{ab}>L_{ab}$ の三つだけである．
これを代入したものが\eqref{ke:eq:k4-protected-inequalities}である．
同系と定理\ref{ng8:componentwise-critical-area}により，
strict inequalities は固定した marked relative orbit 内で必要十分であり，
end collars と全保持 annuli を固定した実際の reduced foliations を与える．
元と同じ circle bundle に持ち上げることで Lagrangian link leaves を得る．
$-M_a>0$ を使えば三通りの $S_a$ の記述も従う．

有向四角形は各頂点で入次数・出次数が一つなので，
forced arrows の終点重複と長さ $2,3$ の cycle は不可能である．
逆に，終点が互いに異なるなら forced graph の入次数・出次数は高々一つである．
Loop は元から許されない．短い cycle がなく，既に四角形でもなければ，
この graph は互いに素な directed paths と isolated vertices の和となる．
これらを任意の巡回順序に並べ，それぞれの終点から次の始点へ arrow を足す．
まだ出辺のない頂点の $S_a$ は全ての他頂点を許すので，追加する arrows は許容される．
一つだけの path ならその終点を始点へ結べばよい．
得られた有向四角形について四つの相対面積構成を行い，
corner 上の全葉を保つことと指定された torus markings を用いて
命題\ref{ke:actual-anchor-fan-criterion}を適用する．
\end{proof}

\begin{corollary}[K2 端を保つ actual 五次 anchor の $K_4$ 実現]
\label{ke:k4-actual-end-anchor}
五次の P0 構成において，一つの component と正の weights $w_a$
$(a=1,2,3,4)$，$\sum_aw_a=1$ を固定し，$\rho_a=2\pi w_a$ とする．
Primitive は\eqref{ke:eq:component-positive-gauge}から exact Moser 移送と
相対不変化で得た同じ $\lambda^{\rm ad}$ を用いる．
十分大きい固定段階 $j$ の後に $N=N_j$，最後に $t$ の閾値を選び，
$\delta=4\pi/N$ の actual moment link を取る．
各 normal face の保持集合には，全 K2 交わりを含む end collars のみを要求する．
Source の compact nodal neighborhoods は，$\delta$ の決定後に
$|\widehat\mu_N|<\delta/2$ の中で選んでよいものとする．

このとき各 face $a$ の puncture $b\ne a$ の正の meridian framing を用いて，
保持 collar の critical leaf 側の境界の period は
\[
 Q_{ab}=c_{ab}+L_{ab}
       =\nu_b-\rho_b<-\rho_b/2<0
\]
となるように選べる．また，これらの同じ actual cycles は
\[
 \sum_{b\ne a}[\beta_{ab}]=-[\alpha_a]
 \quad\text{in }H_1(E_a;\mathbb Z)
\]
を満たす．従って四本の boundary lines の任意の有向四角形 $f$ に対し，
元と同じ marked relative isotopy class 内で
\[
 \int_{\beta_{ab}^{\rm crit}}\lambda^{\rm ad}
   =-M_a\mathbf1_{\{b=f(a)\}},\qquad M_a=\delta-\rho_a<0
\]
を持つ actual anchor foliations を構成できる．
有限個の marked source points も固定できる．
同じ Liouville domain と primitive による filling は，
保持 corner の全 torus 葉，domain と skeleton を変えずに
作用適合 $K_4$ core chart を与える．

必要なら，この anchor の変更を非零 normal moment の有限 band 内で
元の neck 葉族へ戻せる．この変更は全 K2 end collars と上で選んだ
source の compact nodal neighborhoods を保つ．
ただし，この結論は全 neck interval の critical actions の直線性，
反対側 core との切片・整数 shear の一致，または大域作用適合 atlas を主張しない．
\end{corollary}

\begin{proof}
\emph{保持 collar の位置と量化．}
節\ref{ke:core-invariant-primitive-section}の具体的な cut を用いる．
Source torus の残余深度 label を $B$ とし，固定した
$5.4<\theta<5.5$ に対して $B=\theta b_j$ を保持 collar の内側境界とする．
これは actual image の見かけの深度による cut ではない．
この境界は $\min\ell_r>3b_j$ の広い construction domain にあり，
$5b_j<B<9b_j$ の normal-first plateau では，全共通 moment family で
既存 neck の全葉と同じ actual $T^2$ 葉を用いる．
Primitive の full corner gauge への切替えは $B\le5.4b_j$ で完了し，
全 actual K2 交わりは $b_{\rm res}>5.5b_j$ にあり，
$b_{\rm res}=B(1+O(b_j^{-2}))$ である．
従って十分大きい $j$ では，この collar は全 K2 交わりを含む．
境界は一つの full torus であり，corner rounding までの全 end 葉を保てる．

この境界では component normal depth は $[N/2,2N]$ にあり，
他方の source depth は $b_j$ と比較可能である．
\eqref{ke:eq:component-two-action-estimate}の定数は二つの深度比によらない．
そのため，まず $b_j$ を大きくし，次に既存の $n_j,\iota_j$ の後で
$N\gg n_j+b_j+\iota_j^{-1}$ と
$\delta<\min_a\rho_a/8$ を課し，最後に $t$ を小さくして
$(N+b_j)^2/L_t^2\le b_j^{-1}$ とすれば，
全ての境界で
\[
 0<\nu_b\le C/b_j
\]
を得る．$C$ は固定した族と有限個の corner charts に依存してよいが，
$j,N,t$ には依存しない．特に固定 residual compact の定数 $C_j$ を
この corner 誤差に掛けていない．
正の $\rho_*:=\min_a\rho_a$ は最初から固定しているので，
$C/b_j<\rho_*/2$ を先に課せる．この選択には循環がない．

\emph{Period の規約と clutching．}
Corner $ab$ の二つの周期 $1$ の正の meridian generators を $V_a,V_b$，
その全 orbit cycles を $\Gamma_a,\Gamma_b$ とする．
補題\ref{ke:component-meridian-normalization}は，加法定数まででなく厳密に
\[
 \int_{\Gamma_b}\lambda_t^w=\nu_b-\rho_b
\]
を与える．式\eqref{ke:eq:transported-core-primitive-periods}とその後の
centered averaging は exact な差しか加えないので，同じ等式が
$\lambda^{\rm ad}$ に成立する．
閉項 $\gamma_w$ の period は既に $-\rho_b$ に含まれ，
ここで独立な residual closed term 又は第二作用の加法定数を選び直さない．
同じ meridian framing に沿う collar annulus の Stokes により，
この境界 period が $c_{ab}+L_{ab}$ である．よって所要の負値性を得る．

Clutching も同じ meridians について確認する．
直線 $D_a\subset\mathbb P^2$ の normal bundle は $\mathcal O(1)$ である．
その section を，一つの puncture に単純零点を持ち他では非零となるように選ぶ．
Punctures を除いた面上で，この section は normal circle bundle を自明化する．
各 puncture の局所 normal coordinate を固定した正の residual meridian の
fiber winding は，この自明化では零点の puncture で $-1$，他で $0$ である．
Base の正の puncture cycles の和は零なので，これが
$\sum_{b\ne a}[\beta_{ab}]=-[\alpha_a]$ を与える．
補題\ref{ke:closed-component-link}の graph，averaging，Hamiltonian patch の
isotopies は，この SNC plumbing と meridian framings を保つ．
従って同じ relation が actual normal face に成立する．
Corner $ab$ の両側では同じ orbit cycles により
$(\alpha_a,\beta_{ab})=(\Gamma_a,\Gamma_b)$ と
$(\beta_{ba},\alpha_b)=(\Gamma_a,\Gamma_b)$ を使うので，
二つの faces の torus markings も既存の同じ整数基底で一致する．

\emph{同じ marked relative orbit 内での面積指定．}
Face $a$ は pair of pants であり，保持集合はその三つの end collars だけである．
補題\ref{ke:anchor-stokes-budget}により，target
$A_{ab}=-M_a\mathbf1_{\{b=f(a)\}}$ の必要面積
$a_{ab}=A_{ab}-c_{ab}$ の和は reduced 全面積に一致する．
さらに
\[
 a_{ab}-L_{ab}=A_{ab}-Q_{ab}>0 .
\]
Collars の補集合は連結で，各 basin は自由な開部分を持つ．
従って定理\ref{ng8:componentwise-critical-area}，又は
系\ref{ke:k4-protected-anchor-selection}を用い，
元の foliation の $\operatorname{Diff}_0(P\operatorname{ rel}K)$-orbit 内で
この面積を実現できる．抽象的な Reeb tree の同型で代用していない．

有限個の marked source points $p_r$ も固定できることを補足する．
上記 density--Moser construction の補助 primitive を $\eta$ とする．
$K$ から離れた互いに素な小円板内で，
$dg(p_r)=-\eta(p_r)$ という first jets を持つ compactly supported function
$g$ を取る．$\eta$ を $\eta+dg$ に替えてもその微分と end 条件は変わらず，
Moser vector field は全 interpolation parameter で各 $p_r$ において零になる．
従って得られる isotopy 全体がこれらの点を固定する．
これは面積指定の補助 primitive の補正であり，core primitive
$\lambda^{\rm ad}$ の変更ではない．
元の各 $p_r$ は相異なる regular leaves 上にあるから，
この同じ isotopy によりその regularity と marking も保たれる．

補題\ref{ke:closed-component-link}の corner caps でも二つの
meridian periods は負であり，上で確認した整数基底は一致する．
従って命題\ref{ke:actual-anchor-fan-criterion}を適用でき，
同じ Liouville filling から所要の $K_4$ chart を得る．

\emph{Source 近傍と有限 normal band．}
固定した $j,N,t$ の下で，source fibers は全て
$\widehat\mu_N=0$ にあり，anchor は
$\widehat\mu_N=\pm\delta$ にある．
補題\ref{ng8:p0-source-protected-reduction}の $0$ を含む compact interval $J$
を $(-\delta/2,\delta/2)$ の内部へ縮め，同補題の source annuli の全逆像を取る．
これにより各 full source fiber の compact saturated neighborhood を
$|\widehat\mu_N|<\delta/2$ の中に選べる．
既に与えられた大きい source neighborhood を保持する主張ではなく，
この選択を $\delta$ の決定後に行う存在主張である．
$t$ に一様な neighborhood の幅は要らず，$N$ 又は $t$ の閾値を
この選択のために取り直す必要はない．

Anchor の変更は小さいとは限らないので，既存の small interpolation に
直接入れない．面積指定で得た boundary-relative な全 isotopy を $h_s$
$(h_0=\mathrm{id})$ と書き，$h_1$ が元の anchor 葉を新しい anchor 葉へ
写すようにする．非零 normal band では，end collars を保ち，
有限個の marked source sections を固定点へ同定する同じ reduced trivialization を使う．
この trivialization で，
moment cutoff $\chi$ を用いて元の族を
$h_{\chi(\mu)}(\mathcal F^{\rm old}_\mu)$ へ先に替える．
支持は $|q_a-\delta|<\delta/4$ に取り，anchor 近傍で $\chi=1$ とする．
全 $h_s$ が diffeomorphisms で，end collars と marked points を固定するため，
この操作は全 simple-saddle partitions と markings を保つ．
各 moment の全 reduced leaves を持ち上げることによる actual Lagrangian 性は，
系\ref{ke:actual-saddle-moving-neck-interpolation}と同じ reduction の計算で従う．

この前処理後の葉族と，新しい anchor からの Liouville 葉族は，
anchor で同じ marked partition を持つ．
Marked points が相異なる regular leaves 上にある条件は anchor で成立し，
有限個の点について開条件なので，band を縮めれば両族で保たれる．
ここで初めて定理\ref{ke:saddle-moving-relative-interpolation}を適用し，
さらに小さい band で Liouville 葉族と一致させる．
これは保持 corner 上の full torus partition を変えず，
上で選んだ source neighborhoods は全支持の外にある．
反対側の component の band は opposite moment sign を持ち，互いに素である．
この補間は critical actions を全 interval で affine にする操作ではない．
\end{proof}

\subsection{Actual 五次 neck の両端 period を合わせる有限条件}

前系の局所 $K_4$ charts を二重線の両側で選ぶとき，core primitive の
residues と一つの neck primitive の差を同時に追う必要がある．以下では
実数切片の差を actual gauge で計算する．全 moment interval の面積輸送と，
作用 chart の全 open overlaps の構成は，この period 計算とは区別する．

\begin{proposition}[Actual 両端 $K_4$ periods の有限整合条件]
\label{ke:k4-actual-neck-periods}
五次 P0 の一つの固定段階と十分小さい $t\ne0$ を取る．成分を
$i\in\{0,1,2,3,4\}$ で標識し，各成分の weights を
\[
 w_{i,j}>0,\qquad \sum_{j\ne i}w_{i,j}=1,
 \qquad \rho_{i,j}=2\pi w_{i,j}
\]
とする．これらの weights は core construction の前に固定する．
系\ref{ke:k4-actual-end-anchor}により，成分 $i$ の他の四 labels 上の
有向四角形 $f_i$ に対応する actual anchor を選び，
\[
 x_{i;jk}=\mathbf1_{\{k=f_i(j)\}},\qquad
 M_{i,j}=\delta-\rho_{i,j},\qquad
 A_{i;jk}=-M_{i,j}x_{i;jk}
\]
と書く．同じ二重線 $C_{ij}$ の両端には，同じ marked neck family を用い，
その三つの $k$-basins に入る source の数を $n_{ij;k}$ とする．
Critical boundary は source を避け，source は相異なる regular leaves 上にあるものとする．
従って $n_{ij;k}\ge0$，$\sum_{k\ne i,j}n_{ij;k}=5$ であり，
source の保持近傍を固定した相対変更ではこれらの数を変えない．

$i$ 側の正の normal cycle を $\alpha$ として
$\mu=\int_\alpha\lambda_N$ を既存の canonical moment に固定する．
ここで $\lambda_N$ はこの neck 全体で一つの canonical primitive を用い，
必要な averaging の exact transport を施したものである．
$j$ 側の正 normal cycle は $-\alpha$ なので，
$q_{i,j}=\mu$，$q_{j,i}=-\mu$ である．
各 core の $k$-puncture meridian を同じ marked annular sheets に沿って
critical boundary へ運んだ cycles を $\beta_{i;k},\beta_{j;k}$ とする．

このとき実数 $\chi_{ij;k}$ があり，core と neck の closed primitive 差は
\begin{equation}\label{ke:eq:actual-neck-residual-constants}
 \begin{split}
 \kappa^{\rm prim}_{i;k}&=\chi_{ij;k}+\rho_{i,k},\qquad
 \kappa^{\rm prim}_{j;k}=\chi_{ij;k}+\rho_{j,k},\\
 \sum_{k\ne i,j}\chi_{ij;k}&=-2\pi .
 \end{split}
\end{equation}
特に $\chi_{ij;k}$ は二つの core ごとに独立に選べる定数ではない．
$\lambda_N$ による両端の affine critical-action germs は
\begin{equation}\label{ke:eq:actual-neck-affine-germs}
 \begin{split}
 J_{i;k}(\mu)&=\chi_{ij;k}+\rho_{i,k}
                   +x_{i;jk}\rho_{i,j}-x_{i;jk}\mu,\\
 J_{j;k}(\mu)&=\chi_{ij;k}+\rho_{j,k}
                   +x_{j;ik}\rho_{j,i}+x_{j;ik}\mu .
 \end{split}
\end{equation}
Actual smoothing による cycle transport は
\begin{equation}\label{ke:eq:actual-neck-source-shear}
 \beta_{j;k}=\beta_{i;k}+(n_{ij;k}-1)\alpha
\end{equation}
を与える．従って，この framing における二つの affine germs が一致するための
必要十分条件は，各 $k\ne i,j$ について
\begin{align}
 n_{ij;k}&=1+x_{i;jk}+x_{j;ik},
       \label{ke:eq:actual-neck-integer-condition}\\
 \rho_{i,k}+x_{i;jk}\rho_{i,j}
   &=\rho_{j,k}+x_{j;ik}\rho_{j,i}.
       \label{ke:eq:actual-neck-intercept-condition}
\end{align}
切片の三つの差の和は零なので，二重線一つについて独立な実数条件は高々二つである．
この主張は，指定された両端の period germs の整合についての必要十分性である．
その間で affine critical actions を実現する foliation，保持 source 領域を避ける
全 interval の正の面積配分，または全域作用 atlas の存在は含まない．
\end{proposition}

\begin{proof}
\emph{一つの primitive と共通の残余定数．}
三重点を除いた二重線の固定 compact base では，
補題\ref{ke:projected-source-normal-form}を一つの affine frame で用い，
$x'y'=t h_t(p)$ と書ける．除いた三重点の一つを affine 座標の無限遠に取ればよい．
式\eqref{ke:eq:source-inclusive-fixed-frame}の
$d\log x'\wedge dp=-d\log y'\wedge dp$ は全 source にも非零に延びるので，
これから同じ $\lambda_N$ を neck 全体に選べる．
補題\ref{ke:circle-exact-transport}による actual averaging とその後の
Hamiltonian patch は，この primitive の cycle periods を exact 差まで保つ．
Normal moment の向きは $i$ 側の正 meridian へ合わせるが，加法定数を変更しない．

$k$ に対応する K2 end の共通 torus tube では，三重 chart の小さい
canonical primitive を $\lambda_{\log}$ とする．非正則な source gauge では
既存構成通り $G^*\lambda_{\log}$ を用い，新しい $d^c$-primitive を作り直さない．
同じ actual 空間上で
\[
 D=\lambda_N-\lambda_{\log}
\]
は閉形式である．補題\ref{ke:component-meridian-normalization}の normal-period
規格化から $\int_\alpha D=0$ が厳密に成り立つ．
この K2 torus tube は全共通 moment family を含み，両 component 側の end collars
をつなぐ．Triple の整数 lattice では
\[
 \alpha=(-1,1,0),\qquad
 \beta_{i;k}=(-1,0,1),\qquad
 \beta_{j;k}=(0,-1,1)=\beta_{i;k}-\alpha
\]
である．この段落の $\beta$ は K2 end 上の reference cycles を表す．
従って $D$ の二つの residual periods は同じであり，その値を
$\chi_{ij;k}$ と定める．閉形式の period なので torus tube 内の transport によらず，
両側で同じ値を使える．

一方，同補題の二つの meridian の計算と
\eqref{ke:eq:transported-core-primitive-periods}より，
$\lambda_i^{\rm ad}-\lambda_{\log}$ の $k$-meridian period は
$-\rho_{i,k}$，$j$ 側では $-\rho_{j,k}$ である．
各 component collar 上の $\lambda_N-\lambda_s^{\rm ad}$ も閉形式なので，
reference cycle をその critical basin の annular sheets に沿って運んでも同じ値を持つ．
この collar では projected source points は追加 divisor ではなく，
$\mu\ne0$ の component branch 上で双方の primitives は滑らかである．
従って source ごとの未知の実定数を加える必要はなく，
\eqref{ke:eq:actual-neck-residual-constants}の最初の二式を得る．

同じ左 component face において
$\sum_k[\beta_{i;k}]=-[\alpha]$ であり，
$\lambda_N-\lambda_i^{\rm ad}$ の normal period は $\rho_{i,j}$ である．
この\emph{閉差}に relation を適用すると
$\sum_k\kappa^{\rm prim}_{i;k}=-\rho_{i,j}$ となる．
$\sum_{k\ne i,j}\rho_{i,k}=2\pi-\rho_{i,j}$ から
$\sum_k\chi_{ij;k}=-2\pi$ が従う．非閉の primitive 自身を全空間の
homology relation へ直接積分した計算ではない．

\emph{Actual smoothing の整数 shear．}
$k$-basin の正向き regular boundary を取り，critical boundary はその極限で扱う．
その basin は一つの triple puncture と $n_{ij;k}$ 個の source を含む．
Triple cap を戻した regular basin は円板であり，他の二 punctures はその外にある．
従ってそれらの一つで零点を持つ $\mathcal O(1)$ の section を使い，
二つの normal line bundles をこの円板上で自明化できる．
Puncture 近傍の既定 frame との差は winding 零の unit なので meridian marking は変わらない．
これらの frames を用いると，
$h_0=-F_5/\prod_{\ell\ne i,j}L_\ell$ は各 source で単純零点を持ち，
この triple puncture で単純極を持つ．
従って境界上の winding は $n_{ij;k}-1$ である．
Triple puncture の固定した小さい reference circle 上では
$h_t=h_0+O(t)$ の homotopy により winding は厳密に $-1$ のままである．
この circle と現在の basin boundary の間で $h_t$ は正則であり，
そこに含まれる actual projected source の単純零点は $n_{ij;k}$ 個である．
Argument principle により，現在の boundary の winding は $n_{ij;k}-1$ となる．
したがって $t$ ごとに選んだ critical boundary と source の距離に，
$t$ に一様な正の下界を追加してはいない．
Projected source の零点を運ぶ marking はこの整数を保つ．

$i$ 側の正 normal coordinate を $v$，$j$ 側を $u$ とすれば，
$uv=t h_t(p)$ であり，共通 normal action は $v$ を正方向，$u$ を逆方向に回す．
境界上で $v$ の位相を固定した lift が $i$ 側の puncture framing，
$u$ の位相を固定した lift が $j$ 側の framing である．後者の $v$ の位相は
$h_t$ の winding だけ増えるため，
\eqref{ke:eq:actual-neck-source-shear}を得る．
Triple end だけなら winding は $-1$ であり，前段の lattice 計算とも一致する．
Graph，averaging と相対 Hamiltonian の isotopies はこれらの同じ cycles を運ぶので，
この式は actual regular annular sheets とその critical limit に成立する．
これは補題\ref{qg8:framing}の smoothing-clutching 計算を，
source-inclusive な finite-$t$ normal form へ直接適用したものであり，
node の個数だけから任意の cycle transport に shear を割り当てたものではない．

\emph{係数比較．}
補題\ref{ke:anchor-liouville-actions}の gauge 付き比較に
$A_{i;jk}/M_{i,j}=-x_{i;jk}$ と
\eqref{ke:eq:actual-neck-residual-constants}を代入すれば，
\eqref{ke:eq:actual-neck-affine-germs}を得る．
同じ torus 上での framing 比較は
\[
 J_{j;k}(\mu)=J_{i;k}(\mu)+(n_{ij;k}-1)\mu
\]
であるから，二本の affine germs の一次係数と定数項を比較すれば
\eqref{ke:eq:actual-neck-integer-condition}と
\eqref{ke:eq:actual-neck-intercept-condition}に同値となる．
前者は命題\ref{qg8:slope}の整数式と同じであるが，後者では actual
canonical primitives に由来する共通の $\chi_{ij;k}$ が相殺している．
Row sums と $\sum_kx_{i;jk}=\sum_kx_{j;ik}=1$ から切片差の和は零となる．
また共通の左 frame では $\sum_kJ_{i;k}=-\mu$ である．

Normal period が零の閉形式を同じ neck primitive に加えた場合にも，
両側の residual period は同じだけ変わり，切片差は変わらない．
Exact な core 補正も cycle periods を変えない．したがって独立な primitive の
定数変更を許してこの条件を満たしているわけではない．
\end{proof}

\begin{corollary}[等重みの対称四角形系と actual period 整合]
\label{ke:k4-equal-weight-periods}
前命題で全ての $w_{i,j}=1/4$ とする．全十本の二重線で両端の affine
period germs が整合するための必要十分条件は
\[
 f_i(j)=f_j(i),\qquad
 n_{ij;k}=1+2\mathbf1_{\{k=f_i(j)\}}
 \quad(i\ne j,\ k\ne i,j)
\]
である．従って各二重線の source allocation は selected puncture に三個，
残る二つに一個ずつである．対称な有向四角形系は
系\ref{qg8:six-systems}の六つであり，例えば
\[
 f_i(j)=3(i+j)\pmod5
\]
を使える．この場合，実数切片と整数 slope の条件は全て finite $t$ で一致する．

この結論は，その marked allocation を持つ初期 neck family を選び，
その後に source の全飽和近傍を固定する順序で用いる．
既に別の allocation を固定した P0 の relative orbit に，source を動かさず
この配分を実現できるとは主張しない．
\end{corollary}

\begin{proof}
$\rho_{i,j}=\pi/2$ を\eqref{ke:eq:actual-neck-intercept-condition}へ代入すると，
$x_{i;jk}=x_{j;ik}$ に同値である．各側で値 $1$ を取る $k$ は一つなので，
これは $f_i(j)=f_j(i)$ と同値である．整数条件を代入すると source counts を得る．
六つの系と上の代表は系\ref{qg8:six-systems}で証明した．
初期の三穴球面上で有限個の source points を所定の regular basins に配する
marked foliation の選択には，補題\ref{qg8:marked-allocation}の第一段の
boundary-relative isotopy を使える．全 source neighborhoods を固定するのは
この選択の後である．これは全 interval の target areas を実現したことを意味しない．
\end{proof}

\begin{example}[非対称系も許す residue weights]
\label{ke:k4-cyclic-weight-periods}
等重みの条件を外すと，前系の対称性は必要でない．五つの labels の有向五角形を
一つ固定し，その successor を $s$ とする．$f_i$ はこの五角形から $i$ を削除した
有向四角形とする．正の $a_i$ を $\sum_i a_i=1$ となるように選び，
\[
 w_{i,j}=a_j+a_i\mathbf1_{\{j=s(i)\}}
 \qquad(j\ne i)
\]
と置く．これらは正で row sum は $1$ であり，
\eqref{ke:eq:actual-neck-intercept-condition}を全て満たす．
$n_{ij;k}=1+x_{i;jk}+x_{j;ik}$ と配分すれば整数条件も満たす．
隣接した二 labels の二重線では配分は $(3,1,1)$，非隣接なら $(2,2,1)$ である．
例えば $a_i=1/5$ では successor weight は $2/5$，他の三 weights は $1/5$ となる．

実際，$j=s(i)$ の場合には，両側が選ぶ $k$ は $s(j)$ で一致する．
その $k$ に対する両辺は $a_i+a_j+a_k$，他の $k$ では $a_k$ である．
$j,i$ の向きを交換した隣接の場合も同じである．
非隣接の場合，選ばれる $k$ はそれぞれ $s(j),s(i)$ で異なる．
$k=s(j)$ では両辺は $a_j+a_k$，$k=s(i)$ では $a_i+a_k$，
残る $k$ では $a_k$ となる．これで切片式を直接確認した．
この計算は正 weights の全解の分類ではない．
この compatible data の全 moment 実現は定理\ref{ng8:quintic-full-moment}，
全域 atlas と GH 実現の同時選択は定理\ref{ke:quintic-simultaneous-realization}で扱う．
\end{example}

\begin{remark}[既指定データに対する有限障害]
等重みであるにもかかわらず，ある共有 branch に
$f_i(j)\ne f_j(i)$ があれば，対応する二つの punctures で切片差は
$\pi/2$ と $-\pi/2$ となる．これは source shear や exact gauge で消えない．
対称系でも，既に保持した basin の source 数が $(3,1,1)$ の指定値と異なれば，
\eqref{ke:eq:actual-neck-integer-condition}が破れる．
これらは指定 weights・directed-cycle core charts・marked allocation を同時に保つ
straight-branch 接続の障害であり，actual P0 や他の chart 選択を許す
Lagrangian fibration 全体の不存在ではない．
\end{remark}

\begin{remark}[先指定保持領域に対する輸送条件]
一般の固定保持集合に対する系\ref{ke:k4-protected-anchor-selection}の判定には，
最大で十二個の $Q_{ab}$ と四個の $M_a$ を用いる．
六つの有向四角形を列挙して\eqref{ke:eq:k4-protected-inequalities}を検査してもよいが，
同系の forced-arrow 条件は失敗の理由も示す．
例えば一つの face に二つの非負の protected periods があれば，
その固定保持集合ではどの successor も選べない．
全ての $Q_{ab}<0$ なら，どの有向四角形も選べる．
系\ref{ke:k4-actual-end-anchor}は，K2 end collars のみを anchor 上で保持する
標準的な選択について，この負値性と meridian clutching を実際に検証したものである．

Anchor 上でも source regular annuli などを追加して既に固定した場合には，
その最内側境界の $Q_{ab}$ は上の K2 corner 境界の period ではない．
その場合は実際の tail periods を求め直す必要がある．
一般の固定領域が補集合を分断する場合には，総量一致と個々の保護面積の余裕に加え，
補集合成分への面積配分と critical regions との incidence に応じた
有限輸送条件を検査する．

命題\ref{ke:actual-anchor-fan-criterion}は，必要な actual anchor 葉が得られた後の
core cone filling と action chart を与える．
Source を跨ぐ中央 neck では，
命題\ref{ng8:source-corrected-area-demand}の wall 補正と全 interval の edge cuts，
命題\ref{ng8:source-corrected-anchor-matching}の切片・整数 shear が必要である．
標準五次の directed-cycle charts については，
命題\ref{ke:k4-actual-neck-periods}が反対側の critical lines の切片と
normal framing を actual residues と source counts の有限式へ帰着した．
その式を満たした後にも，source 周囲の全保持領域を含む全 interval の
marked interpolation と正の面積配分，および全 open overlaps の whole-fiber 一致を
別に構成する必要がある．独立な exact gauge による実数切片の変更や，
端点だけの面積検査で代用してはならない．
これらを\eqref{ke:eq:anchor-intercept}又はその gauge 付きの式と合わせて確認した後に，
命題\ref{ke:moment-relative-replacement}を用いる．
局所 $K_4$ chart の存在だけから，同じ射影での全域 atlas/GH 実現は導かない．
初期 source 葉を選ぶ自由のある compatible な五次データでは，
定理\ref{ng8:quintic-full-moment}がこれらの全 interval 条件を実際に満たす．
その全域への接続を次の定理で行う．
\end{remark}

\begin{remark}[Irrational period による具体的な障害]
固定した anchor の $A/(\delta_a-\rho_a)$ が無理数なら，その Liouville filling
の branch は整数作用格子に対して有理方向を持たない．
整数可逆な作用座標変換は有理方向を有理方向へ，無理方向を無理方向へ写すので，
この filling に作用適合 matroidal core chart を与えることはできない．
これは Liouville cone construction が自動的に atlas を与えない具体的理由である．
枝を含む regular annulus の内部で正の面積を小さく移すことで，end collars と
normal moment を保ったまま critical period を連続に変えられる場合，この
無理数条件を満たす anchor foliation は存在する．その小変更の可否も，
保持集合の補集合内に対応する可動領域がある場合に限定する．
Critical action が直線であることと，その直線が整数作用格子に適合することは
異なる．一般的な cone-extension 原理や action-angle 原理の新規性は主張しない．
\end{remark}

\subsection{五次の作用 atlas と KE 計量実現の同時選択}

\begin{theorem}[Compatible 五次データの同時実現]
\label{ke:quintic-simultaneous-realization}
定理\ref{ke:global-realization}の一般性条件を満たす一つの五次全平面退化を固定する．
五つの成分について，正の weights $w_{i,j}$，有向四角形 $f_i$，
各二重線の五つの source の labelled basin assignment を固定し，
命題\ref{ke:k4-actual-neck-periods}の row sums と二つの有限整合条件
\eqref{ke:eq:actual-neck-integer-condition}，
\eqref{ke:eq:actual-neck-intercept-condition}を満たすとする．
このとき，一つの固定した marked 木系 $T$ と，十分小さい全ての複素 $t\ne0$ に対して
actual 負 KE 形式に関する全域 Lagrangian torus fibration
\[
 \widehat\pi_t:X_t\longrightarrow B_5(T)
\]
を選び，次を同時に満たせる．
\begin{enumerate}
\item 同じ $\widehat\pi_t$ の作用格子に適合する大域 matroidal atlas があり，
五つの core charts は指定した $K_4$ charts，全 branch denominator は $1$ である．
Focus values は通常の matroidal charts の定義域から除き，
その穿孔近傍には実際の focus affine structure を用いる．
\item 同じ標識付き収縮との合成 $\widehat f_t=p_T\widehat\pi_t$ に対して
\begin{equation}\label{ke:eq:quintic-simultaneous-distortion}
 \sup_{x,y\in X_t}
 \left|R_t^{-1}d_{g_t}(x,y)
       -d_\square(\widehat f_t(x),\widehat f_t(y))\right|
 \longrightarrow0.
\end{equation}
全 $\widehat f_t$-fibers の正規化 ambient 直径も一様に零へ向かう．
\end{enumerate}
初期の source leaves とその全飽和近傍は構成中に選ぶ．既に指定された任意の
大きい source 近傍や異なる allocation を固定する相対存在は主張しない．
$t$ 方向に連続又は滑らかな fibration 族を要求せず，収束速度も追加しない．
また，各 $t$ で同じ射影に二つの性質を持たせる主張であり，作用 atlas の $t$ 方向の収束，
極限基底上の integral affine 構造，あるいは $d_\square$ の作用座標に関する
Hessian 性又は Monge--Amp\`ere 方程式を結論しない．

特に全 $w_{i,j}=1/4$ とし，系\ref{ke:k4-equal-weight-periods}の六つの
対称四角形系のいずれかと source allocation $(3,1,1)$ を選べるため，
この五次の同時実現は追加の未検証解析仮定を必要としない．
この対称な選択では各 triangle に五つの nodal values が入る．
\end{theorem}

\begin{proof}
\emph{固定段階で同じ解析領域と marked quotient を使う．}
定理\ref{ng8:quintic-full-moment}を全十本の二重線へ適用する．
正 weights と有限整合データを先に固定し，その最小 residue に応じて
$b_j$ と $N_j$ を大きくする．これらは既存 P0 の許容される cut 条件を強めるだけであり，
最後に全有限条件に共通な $t$ の閾値を取る．
同定理で選んだ初期の thin-tail 葉族から，通常の P0 と，面積指定を施した新しい構成を
それぞれ作る．両者は同じ actual normal circles，canonical moments，anchor cuts，
component domains と invariant primitives を用いる．
全 K2 end collars と保持 corner の全 torus leaves，および
$|\mu|<\delta/2$ 内で初期に選んだ全 compact nodal neighborhoods では一致する．
基準となる rooted trees と source の basin・順序を固定するため，
全 stage と全小 parameter で同じ marked $T$ を用いられる．
解析的な connector bounds は同じ moment 上の $P_j$ 全体に対するものであり，
これらの葉の微分に依存しない．

各 neck には source を跨いで指定 affine critical actions を持つ実際の reduced 葉族がある．
その商は source values を含む marked product であり，regular strata 上では滑らかである．
各 anchor の periods は $A_{i;jk}=-M_{i,j}x_{i;jk}$ なので，
命題\ref{ke:actual-anchor-fan-criterion}により同じ Liouville domain と skeleton を
$K_4$ chart を持つ cone filling で満たす．
定理\ref{ng8:quintic-full-moment}の最後の parameter-relative 面積補正は，
Liouville family と neck family の指定 open germs を保つ．
従って core--neck の全開 overlap で実際の葉が一致し，K2 の全開 overlap も保存される．
Normal faces は同じ $\mu$-levels であり，corner と cap の cuts は保持した同じ全 torus の和，
core 側の cuts は同じ $\lambda$ の Liouville radial levels である．
従ってこれらは新しい葉族についても whole-fiber 飽和となる．
同じ飽和 cut と rounding を用いれば，
補題\ref{glue:closed-whole-fiber-quotient}が compact Hausdorff な閉商を与える．
局所 fibers の連結性，actual Lagrangian 性，特異 strata の等方性は各局所構成から従う．
Marked product と core cone の boundary が一致するので，
命題\ref{ke:moment-relative-replacement}の四条件を満たす．

\emph{実際の作用格子を大域 atlas へ接続する．}
周期 $1$ の未除算 periods $J,\mu,\rho$ を，節\ref{atl:section}の規約に合わせて
core と branch の全作用座標も含めて一斉に $2\pi$ で割る．
この同一の換算で整数 slopes，cycle shears，有限整合式は変わらない．
各 core には指定した作用適合 $K_4$ chart がある．
各開 branch では critical actions の整数 affine 性と，simple saddle の
各 incident sheet 上の transverse action の strict monotonicity により，
補題\ref{atl:qone-chart}が denominator $1$ の chart を与える．
共通 normal action は，この branch chart と隣接する core chart の双方で
ambient-affine であり，branch tangent 上の勾配は primitive かつ非零である．
正則 faces では実際の fibration の action charts を用いる．
従って命題\ref{atl:gluing-criterion}により，すべての transitions と逆写像は
ambient integer affine maps の制限になる．
三つの incident sheets の同時延長は命題\ref{qg8:star-transition}にも明示されており，
その証明は対称性でなく $n_{ij;k}=1+x_{i;jk}+x_{j;ik}$ と各四角形の predecessor の
一意性だけを使う．以下で実数切片を含めた延長も具体的に確認する．

一つの二重線 $ij$ を固定し，残りの三 labels を $k$ と書く．
$n_k=n_{ij;k}$ とし，
$x_k=x_{i;jk}$，$x'_k=x_{j;ik}$，
$y_k=\mathbf1_{\{f_i(k)=j\}}$，$y'_k=\mathbf1_{\{f_j(k)=i\}}$ と置く．
共通の左 neck frame で正規化した実際の作用を
$h=\mu/(2\pi)$，$J_k=J_k^N/(2\pi)$ とし，
各 incident regular sheet 上で
\begin{equation}\label{ke:eq:quintic-branch-action-coordinates}
 b_k=\frac{\chi_{ij;k}}{2\pi}+w_{i,k}+x_kw_{i,j},\qquad
 \tau_k=-(J_k+x_kh-b_k)
\end{equation}
と取る．Critical branch で $\tau_k=0$，そこから sheet 内へ向かう向きで
$\tau_k>0$ である．これは puncture から critical leaf までの面積が最大になる規約と，
simple saddle の横断方向の厳密単調性による．
$N_{\rm br}=\ZZ v\oplus\ZZ u_1\oplus\ZZ u_2$，$u_3=-u_1-u_2$ を用い，
product branch chart を各 sheet 上で $F_{\rm br}=hv+\tau_ku_k$ と書ける．

$i$ 側 core の正規化した作用を $I^i_\alpha,I^i_{\beta_k}$ とすると，
同じ primitive 差の計算は
\[
 h=I^i_\alpha+w_{i,j},\qquad
 J_k=I^i_{\beta_k}+\frac{\chi_{ij;k}}{2\pi}+w_{i,k}
\]
を与える．従って $\tau_k=-(I^i_{\beta_k}+x_kI^i_\alpha)$ である．
Core face の座標 $(s,\zeta)$ では
\[
 \binom{I^i_\alpha}{I^i_{\beta_k}}
 =\begin{pmatrix}-1&y_k\\x_k&-1\end{pmatrix}\binom{s}{\zeta}.
\]
四角形には二周期がないので $x_ky_k=0$ であり，
$\tau_k=\zeta$，$h=-s+y_k\zeta+w_{i,j}$ を得る．
従って core rays から product star への全三面共通の affine extension は
\begin{equation}\label{ke:eq:quintic-core-branch-extension}
 r_{ij}\longmapsto-v,\qquad
 r_{ik}\longmapsto u_k+y_kv,\qquad
 \text{平行移動項}=w_{i,j}v.
\end{equation}
$\sum_k y_k=1$ と $\sum_k u_k=0$ により $K_4$ の唯一の関係
$r_{ij}+\sum_k r_{ik}=0$ を保つ．任意の二本の $u_k$ と $v$ は格子基底なので，
線形部分は行列式 $-1$ の整数格子同型である．

反対側では $h=-I^j_{\alpha'}-w_{j,i}$ であり，source shear により
\[
 J_k=I^j_{\beta'_k}+\frac{\chi_{ij;k}}{2\pi}+w_{j,k}-(n_k-1)h.
\]
$n_k-1=x_k+x'_k$ と切片整合式を代入すると
$\tau_k=-(I^j_{\beta'_k}+x'_kI^j_{\alpha'})=\zeta'$，
$h=s'-y'_k\zeta'-w_{j,i}$ となる．
この側の格子同型は $r_{ji}\mapsto v$，$r_{jk}\mapsto u_k-y'_kv$，
平行移動項は $-w_{j,i}v$ である．両者を合成すれば
\begin{equation}\label{ke:eq:quintic-affine-full-transition}
 \zeta'=\zeta,\qquad
 s'=-s+(y_k+y'_k)\zeta+w_{i,j}+w_{j,i}.
\end{equation}
全三面の平行移動は同じ $(w_{i,j}+w_{j,i})r_{ji}$ であり，
$x_k\ne x'_k$ 又は非対称な正 weights でも一つの ambient integer affine map になる．
ここで $\chi_{ij;k}$ が相殺するのは，両側を同じ neck primitive で比較したためである．
この計算の入力は既に全 open collars で一致する実際の葉と作用であり，
整数行列だけから葉の接着を導いてはいない．
Cocycle identity は実際の chart transitions の合成から成立する．
保存した nodal neighborhoods の穿孔基底には同じ focus action lattice を用い，
その monodromy を通常の matroidal chart で埋めることは要求しない．

\emph{同じ射影へ全域距離評価を移す．}
基準の P0 写像を $f_{j,t}$ とすると，
命題\ref{ke:moment-relative-replacement}により同じ保持 corner 上では
$\widehat f_{j,t}=f_{j,t}$ とでき，それ以外も
\[
 \sup_{x\in X_t}d_\square(\widehat f_{j,t}(x),f_{j,t}(x))
 \le C\frac{1+\log(N_j+1)}{R_t}
\]
となる．基準の P0 の距離証明に葉内経路や reduced isotopy の微分評価は入らず，
同じ analytic cuts と全 moment connector bounds を用いるので，
初期葉を上の marked class 内で選び直しても同じ遅い対角選択が使える．
系\ref{ke:relative-replacement-gh}から
\eqref{ke:eq:quintic-simultaneous-distortion}と全 fiber 直径の主張を得る．
基底の parameter 化は，既に構成した atlas を homeomorphism で運ぶものであり，
非直線の critical action を座標変更で直線化する操作ではない．

等重みと対称六系は系\ref{ke:k4-equal-weight-periods}で全有限条件を満たす．
各 triangle の node 数 $3+1+1=5$ は定理\ref{qg8:unique-weights}の
同じ midpoint の組合せ計算による．以上の過程は各固定 $t$ で行い，
parameter 方向の滑らかな族又は任意指定された source fibers への相対存在を加えていない．
\end{proof}
